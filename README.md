# OrderFlow : A complete event driven .NET application

## Includes:
    * REST Order API
    * gRPC Inventory service
    * Kafka event processing
    * PostgreSQL persistence
    * Notification worker
    * Docker images
    * Docker Compose environment (to run the complete workflow)

## Target platform
    * Win11 / Linux
    * .NET 8 LTS
    * Docker Desktop/Engine
    * PostgreSQL
    * Kafka KRaft
